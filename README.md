# Projet Speed Dating — Tinder

Analyse exploratoire de données (EDA) réalisée dans le cadre de la formation Jedha (Bloc de certification #2), pour le compte fictif de Tinder.

## 🎯 Objectif

Comprendre ce qui pousse deux personnes à vouloir se revoir après un speed dating, à partir de données collectées lors d'expériences de speed dating (2002-2004).

## 📊 Dataset

Speed Dating Data (fourni par Jedha), incluant pour chaque rencontre :
- Les décisions de chacun des deux participants (souhait ou non d'un second rendez-vous)
- Les notes données sur 6 critères : attractivité, sincérité, intelligence, fun, ambition, intérêts partagés
- Des données de profil (démographie, habitudes, auto-évaluation, style de vie)

## 🛠️ Outils

- **Python** (pandas, matplotlib/seaborn)
- Jupyter Notebook

## 📓 Notebook

- [speed_dating_analysis.ipynb](./speed_dating_analysis.ipynb)

## 🔍 Contenu de l'analyse

- Statistiques descriptives sur les taux de match et les 6 attributs évalués
- Attributs les moins désirables chez un partenaire (homme vs femme)
- Importance perçue de l'attractivité vs son impact réel sur le match
- Intérêts partagés vs origine ethnique partagée dans la décision de second rendez-vous
- Écart entre auto-évaluation et perception par les autres
- Effet de l'ordre du rendez-vous dans la soirée sur le taux de réponse positive
- Interprétations et conclusions pour chaque visualisation
